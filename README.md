# 视频字幕批量处理工具 (SubRename)

一个基于 Python Tkinter 的图形化工具，用于批量处理视频和字幕文件的匹配、复制和重命名操作。

## 功能特性

### 📁 标签页1：匹配改名（字幕复制）
- **拖拽添加**：支持拖拽视频和字幕文件到列表（需安装 tkinterdnd2）
- **自动排序配对**：按文件名自动排序，视频与字幕一一配对
- **智能复制**：将字幕文件复制到对应视频所在目录，并重命名为与视频相同的名称
- **冲突处理**：遇到已存在文件时，可选择覆盖、跳过或取消操作
- **批量操作**：支持一键清空、删除选中文件等管理功能

### 🔢 标签页2：排序命名（集数重命名）
- **模板提取**：通过选择基础文件自动识别命名格式（如前缀、后缀、数字位数）
- **批量重命名**：按照模板格式对多对视频和字幕进行连续编号重命名
- **自动移动**：将重命名后的文件移动到基础文件所在目录
- **自定义起始号**：可设置起始数字，灵活控制编号序列
- **安全保护**：操作前确认提示，避免误操作

## 支持的文件格式

### 视频文件
`.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`, `.webm`

### 字幕文件
`.ass`, `.ssa`, `.srt`, `.sub`, `.vtt`

## 安装依赖

```bash
pip install tkinterdnd2
```

> **注意**：如果不安装 `tkinterdnd2`，程序仍可正常运行，但将无法使用拖拽功能。

## 使用方法

### 启动程序
```bash
python SubRename.py
```

### 标签页1：匹配改名操作流程
1. **添加文件**：
   - 方式一：拖拽视频和字幕文件到列表区域
   - 方式二：（当前版本仅支持拖拽，可扩展添加文件选择按钮）

2. **检查列表**：确保视频和字幕文件数量相同

3. **执行操作**：点击"一键改名"按钮
   - 程序会按文件名排序后配对
   - 将字幕复制到视频所在目录
   - 字幕文件名改为与视频相同（保留原扩展名）

4. **管理文件**：
   - "删除选中"：移除列表中不需要的文件
   - "一键清空"：清空整个列表

### 标签页2：排序命名操作流程
1. **选择基础文件**：
   - 点击"选择基础文件"按钮
   - 选择一个视频文件作为模板（如：`[动画名称] [01] [1080P].mp4`）
   - 程序会自动查找同名的字幕文件，如有多个需手动选择

2. **设置起始数字**：
   - 在"起始数字"输入框中设置第一个文件的编号（默认为 1）

3. **添加待处理文件**：
   - 拖拽需要重命名的视频和字幕文件到列表
   - 确保视频和字幕数量相同

4. **执行重命名**：点击"排序命名"按钮
   - 程序按文件名排序后配对
   - 按照模板格式生成新文件名（如：`[动画名称] [02] [1080P].mp4`）
   - 将所有文件移动到基础文件所在目录

5. **管理文件**：
   - "删除选中"：移除列表中不需要的文件
   - "清空列表"：清空整个列表

## 命名规则说明

### 数字识别模式
程序使用正则表达式 `(?<![a-zA-Z0-9])\d+(?![a-zA-Z0-9])` 识别文件名中的独立数字部分。

**示例**：
- `[柯南] [38] [1080P].mp4` → 识别出 `38`，位数为 2
- `Episode_007.mkv` → 识别出 `007`，位数为 3
- `S01E05.mp4` → 识别出 `01`（第一个匹配），位数为 2

### 重命名格式
```
{前缀}{编号}{后缀}.{扩展名}
```

其中：
- **前缀**：数字之前的所有字符
- **编号**：根据起始数字递增，保持与模板相同的位数（自动补零）
- **后缀**：数字之后的所有字符（不含扩展名）
- **扩展名**：保留原文件的扩展名

## 注意事项

⚠️ **重要提示**：
1. **备份数据**：重命名和移动操作不可撤销，建议操作前备份重要文件
2. **文件数量**：两个标签页都要求视频和字幕文件数量完全相同
3. **文件冲突**：遇到同名文件时会提示是否覆盖，请谨慎选择
4. **排序规则**：文件按文件名（basename）自然排序，请确保文件名符合预期顺序
5. **路径限制**：标签页2会将所有文件移动到基础文件所在目录

## 常见问题

### Q: 拖拽功能无法使用？
A: 请安装 tkinterdnd2：`pip install tkinterdnd2`

### Q: 如何确保文件正确配对？
A: 程序按文件名排序后配对，建议在添加文件前确保文件名有规律的顺序（如按集数命名）

### Q: 能否自定义命名格式？
A: 当前版本通过基础文件自动提取格式。如需更灵活的定制，可修改代码中的 `extract_digits_pattern` 方法

### Q: 移动文件失败怎么办？
A: 检查目标目录是否有写入权限，确保文件未被其他程序占用
